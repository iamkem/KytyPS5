User explicitly requested removal of **Occlusion Query Audit**, **Ready Pipeline Reuse**, and to abandon the ineffective experimental game **Engine Occlusion Culling** switches. The previous 4-variant A/B showed no reduction in guest PM4 draw packet counts. The objective remains *materially fewer graphics operations at a distance*, but never invent new convars or render suppression based only on names.

Integrated runtime changes, in isolated worktree `C:\Users\hoang\.devspace\worktrees\KytyPS5-93e7e50d`:

Legacy keys found in already-saved `launcher-settings.json` are ignored by `clean()` and are discarded by the **next normal save**. Do not rewrite the user's saved file by a build/test.

- Removed native `KYTY_READY_PIPELINE_REUSE` gate and synchronous pending graphics pipeline adoption. The existing original asynchronous completed-pending adoption under acquire/release remains unchanged.
- Removed Stage2D `KYTY_ENGINE_CULLING` loader overlay. Existing `KYTY_GAME_CONVARS` behavior, original index-culling compatibility and the proven Distance Detail overlay are preserved.
- Standalone dormant header/policy sources and prior diagnostic docs are **not imported or referenced** by the emulator/launcher; do not reactivate in normal builds. Historical docs remain for reproducibility of the NO-GO decision. The four old experiment test files have been repurposed into explicit retirement/absence regression tests. This is a runtime/launcher removal; dormant untracked files have not been physically deleted from the isolated research tree.

## Current factual recommendation

**Keep existing Graphics Detail Lowest + Distance Detail Aggressive** as the already-installed source-backed far-detail/shadow reduction. They overlap: distance detail does not compound the 480/60 reduction when Lowest is already selected. Do not stack new toggles; do not re-enable index-buffer culling (`doIndexBufferCulling=true`)—historically generated ~2,800 additional compute dispatches/frame and reduced standing FPS on a source test. Do not guess GPU visibility, draw-count reductions or culling from unrelated names.

There is **no further validated safe far-graphics improvement to implement in this iteration**. A future candidate only qualifies if it has (1) source-level observed semantics on guest 1.07 or demonstrable GPU command change; (2) repeated matched scene/position showing concrete reduced GPU/CPU workload or actual FPS; (3) image correctness for near/opaque/shadow/reflections and no disappearing geometry; and (4) memory and BSOD safety. Do not schedule/execute more gameplay or shader precompiles from DevSpace.
