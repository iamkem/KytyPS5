Limited to verified game version 1.07 and exact original profile text; does nothing if the game uses another profile. Check image correctness before normal play.

Table Read-only Pass: Independent of Shader Translation Mode. Default Off. Experimental CPU-only optimization skips only an empty writable-buffer traversal in TableBlocks for stages proven to contain no writable/atomic resources. No cache conversion. Use Off for immediate rollback; measured FPS benefit is not yet proven.

Table Prefetch Dedupe: G2-G CPU experiment, default Off. Omits only immediately repeated cache-line prefetch hints in a single TableEvaluate dependency level; does not remove page checks or actual memory reads. Independent of G2-D and shader mode. Benefit must be measured; switch Off to roll back without rebuilding caches.

Scene Benchmark: Optional, uses lightweight frame-time counters. After pressing Play, click Measure 15s in the separate window and return to the game within 5 seconds. No automatic input, GPU capture, save replacement or shader compilation.

Shader Translation Mode: Standard uses the current production cache (0x0); Experimental uses the separate precompiled 0x3 store, with native integrity checks at launch. Restore Standard and press OK to save the rollback; caches are never copied, deleted or promoted by this selector. Update Missing Shaders remains Standard-only.

Presets set the actual internal render resolution and detail. Existing RAM16 and memory settings are never changed.

Steam integration

RAM Safety limits background shader work under low RAM and uses adaptive guest backing and idle-texture retirement. Pipeline eviction follows independent RAM Diet and GPU VRAM policies; Stutter Guard has been removed. RAM16 is independent. Neither mode guarantees BSOD prevention.
